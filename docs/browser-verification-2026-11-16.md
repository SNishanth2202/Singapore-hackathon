## Major-issue fixes and sample-data follow-up

The follow-up regression run passed 90 backend tests (one optional test skipped), 18 prospecting tests, and 18 browser tests (live Terra cloud ingestion skipped). Both frontend and backend builds passed again before publication.

- A new service request after a customer declines now reopens human attention without restarting outreach. The regression reproduces “No, not interested” followed by “nvm i want 5g”.
- Sales funnel stages use distinct, nested company cohorts and include autonomous outreach authorisation. Agent escalation percentages use that agent's executions as the denominator. Memory and MongoDB analytics return compatible geography, industry and service breakdowns.
- Discovery handoffs retain each hypothesis's own citations, offering identifier and question. Account briefs match exact active offerings instead of broad category substrings.
- Outbound messages render readable paragraphs rather than literal HTML. Synthetic accounts cannot send through a real email provider.
- Research questions use the retained service rather than a rejected suggestion. Headline-only need statements use reported/conditional wording.
- Settings now save the actual prospecting interval. Company research disables the ranking handoff when there are no accepted hypotheses.
